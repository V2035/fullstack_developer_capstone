# Dealership Review Application

IBM Full Stack Software Developer Capstone project.

## Overview
A dealership review web application that lets users browse dealerships, view dealer details, and submit reviews. This repository is the working project scaffold; the application code, API responses, CI/CD results, and deployment evidence will be added as the implementation is completed and verified.

## Intended technology stack
- **Frontend:** React
- **Backend/API:** Django and Django REST Framework
- **Additional services:** Node.js/Express (where required by the course architecture)
- **Database:** MongoDB
- **CI/CD:** GitHub Actions
- **Deployment:** To be selected and documented after successful deployment
